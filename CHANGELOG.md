# Unlock FPS

## v1.1

### Türkçe

- Widget’ta gönderim sırasında yenileme simgesi döner. İstek gönderildiğinde hedef Hz görünür kalır ve iki saniye boyunca yeşil onay işareti ile **Gönderildi** yazısı gösterilir.
- Kayıtlı hedef yoksa widget’taki **Profil seç** düğmesi uygulama seçimini açar.
- Uygulama ikonu siyah zeminli nabız amblemiyle yenilendi.
- Mobile Legends, Roblox ve Minecraft’ın seçim yapılmadan hedef listesine eklenmesi düzeltildi. Eski profillerdeki yüklü olmayan uygulamalar temizlenir.
- Uygulama kurulduğunda veya kaldırıldığında ilgili kayıt güncellenir. Otomatik gönderim hazır listeyi kullanır. Normal modda seçim boşsa istek gönderilmez.
- Ana ekrandaki kalıcı ipucu kaldırıldı. Beast Mode açıklaması, başlatılabilen uygulamalar için hangi yenileme hızının istendiğini belirtecek şekilde güncellendi.

### English

- The widget’s refresh icon spins when tapped. A green check and **Sent** appear for two seconds after a request is sent, with the target Hz still visible.
- When the saved profile has no targets, **Choose profile** opens the app picker.
- Replaced the launcher icon with a monochrome pulse emblem.
- Fixed Mobile Legends, Roblox and Minecraft being selected by default. Apps missing from the device are removed from existing profiles.
- Package changes update individual entries. Automatic reapply uses the cached list and skips sending when the normal profile is empty.
- Removed the persistent home-screen tip and revised the Beast Mode description to explain the refresh rate it requests for launchable apps.
